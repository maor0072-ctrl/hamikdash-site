# hamikdash.co.il - אתר עמותת אורות האמונה - בני משה

אתר סטטי (HTML/CSS בלבד, בלי תלויות ובלי שלב בנייה), מיועד לאחסון ב-Cloudflare Pages.

## מבנה

- `index.html` - דף בית
- `about.html` - אודות העמותה, הכולל, הייעוץ והסיוע
- `torah.html` - מדור התוכן התורני
- `donate.html` - תרומות
- `contact.html` - יצירת קשר
- `assets/style.css` - גיליון העיצוב היחיד
- `_headers` - כותרות אבטחה ומטמון (נקרא על ידי Cloudflare Pages)
- `robots.txt`, `sitemap.xml` - קידום אורגני

## פריסה

1. הרפוזיטורי מחובר ל-Cloudflare Pages.
2. Build command: ריק. Output directory: `/` (שורש).
3. כל דחיפה ל-`main` מעלה גרסה חדשה לאוויר תוך שניות.

## דומיין

`hamikdash.co.il`, רשום ב-LiveDNS. שרתי השמות מופנים ל-Cloudflare.
**רשומות הדואר (MX ו-`mail`) חייבות להישאר מכוונות לשרת של LiveDNS (62.219.78.231)** אחרת תיבות הדואר בדומיין נשברות.
